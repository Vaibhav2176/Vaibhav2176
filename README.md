## Featured projects

### [NetSage AI](https://github.com/Vaibhav2176/NetSage-AI)

An AI-assisted network troubleshooting and configuration diagnostic assistant for analyzing Cisco and networking scenarios.

NetSage AI uses deterministic rule validation before passing structured findings to an optional Gemini diagnosis layer. Engineers can review, approve, edit, or reject recommendations, and review decisions are recorded in an audit log.

The repository documents approximately 34 pattern-based troubleshooting rules and includes a 31-test automated suite.

**Stack:** Python, Streamlit, pandas, Gemini API, networking

**Links:** [Repository](https://github.com/Vaibhav2176/NetSage-AI) · [Live demo](https://netsage-ai-by-vaibhav2176a.streamlit.app/)

### [Engineering Portfolio](https://github.com/Vaibhav2176/Portfolio)

A personal portfolio site for presenting projects, technical work, and professional information through a focused web experience.

**Links:** [Repository](https://github.com/Vaibhav2176/Portfolio) · [Live site](https://www.vaibhavamulani.me/)

### [ToolVerse](https://github.com/Vaibhav2176/toolverse-hub)

A deployed utility platform built with TypeScript and React.

ToolVerse organizes utilities across categories such as calculators, converters, text tools, generators, student tools, developer tools, design tools, finance, date and time, mathematics, productivity, and writing. Its tool registry is designed to discover additional tool batches automatically, so a fixed feature count is intentionally not stated.

The repository includes Vite, Tailwind CSS, Radix UI components, React Router, ESLint, and Vitest testing support.

**Stack:** TypeScript, React, Vite, Tailwind CSS, Radix UI, React Router, Vitest

**Links:** [Repository](https://github.com/Vaibhav2176/toolverse-hub) · [Live site](https://toolverse-hub.vercel.app/)

### [AI-Powered Customer Support Ticketing System](https://github.com/Vaibhav2176/AI-Powered-Customer-Support-Ticketing-System)

A Salesforce DX project for a telecommunications customer-support workflow.

The project configures Case fields, SLA rules, record-triggered Flows, email alerts, support profiles, reports, and Agentforce metadata. The repository documents a verified Agentforce conversation-preview response, while also noting that successful end-to-end AI troubleshooting guidance and deployment to a separate Salesforce org still require validation.

**Stack:** Salesforce Service Cloud, Salesforce Flow Builder, Agentforce, Lightning App Builder, Salesforce Reports

**Links:** [Repository](https://github.com/Vaibhav2176/AI-Powered-Customer-Support-Ticketing-System)
